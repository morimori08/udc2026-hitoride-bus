# 南部バスの GTFS（データの空白）— 2026-11-01 確認

## 事実
- GTFSデータリポジトリ（api.gtfs-data.jp）の青森県のフィード29件に、南部バスは無い。
- 一覧サイト「全国の公共交通GTFSオープンデータ一覧」（https://bustime.jp/GtfsAgency/gtfs_list/ ）に「南部バス(地図)」の行がある。配信元は PTD-HS（https://www.ptd-hs.jp/ 、公共交通データ HUB システム、運営: ジョルダン株式会社）。停留所数 1,310、有効期間 2026-11-01〜2026-11-30、最終更新 2026-10-28、ライセンス欄は空欄。
- PTD-HS の利用には利用登録（ジョルダンとの利用契約）が必要で、ログイン後に API キーでダウンロードする。
- PTD-HS 利用規約（https://www.ptd-hs.jp/static/PTD-HS-UserPolicy.pdf 、2018-10-12 施行）
  - 別紙B 料金表: みちのりホールディングスの「岩手県北自動車（南部バス）」の GTFS-JP は 0 円。
  - 第31条（禁止事項）(4)「本サービスの内容や本サービスにより提供される情報を、第三者に利用させる行為」。(3)「利用契約等に違反して、第三者に本サービスを利用させる行為」。
- 南部バスのバスロケーションは、標準的なバス情報フォーマット（GTFS-JP/RT）準拠と案内されている（両備システムズの資料 https://www.ryobi.co.jp/application/files/9216/1719/4221/Bus-Vision_nannbu.pdf ）。

## 推論
- 無料で取得はできるが、公開アプリに組み込んで誰でも使える形にするのは第31条(4)に当たる可能性が高い。CC BY のような「自由に使ってよい」オープンデータではない。アプリには入れない（2026-11-01 推奨で判断）。
- 南部バスは八戸市内や三戸郡も走る（路線ごとの範囲は一次情報で未確認）。同梱データでの「行き先ゼロ」は、南部バスが単独で走る地区で実際より多く出ている。
- 言い方の推奨: 「八戸圏のGTFSオープンデータ（4事業者）で計算すると、バス停の44%で、子どもがひとりで行けて帰れる行き先がゼロ。南部バスのデータは登録制で第三者への提供が禁じられているため、この計算に入っていない」。
