# ひとりで、バスに乗れた。

子どもが「ひとりで行けて、門限までに帰ってこられる」場所を、公共交通オープンデータ（GTFS）から地図に描く Web アプリ。アーバンデータチャレンジ2026 応募作品（一般部門・アプリケーション・道路・交通）。

## 動かし方
静的ファイルだけで動く。サーバ側の処理はない。

```bash
python3 -m http.server 8794 --directory app
```

http://localhost:8794 を開く。公開版: https://morimori08.github.io/udc2026-hitoride-bus/

## しくみ
- `app/app.js` が GTFSデータリポジトリ API から GTFS の zip を取得し、JSZip で展開する。
- 行き: 家から徒歩圏のバス停を起点に、出発時刻から所要上限までに着けるバス停を求める（乗りかえ0回か1回）。
- 帰り: 家の徒歩圏のバス停に門限までに着く便を逆にたどり、バス停ごとの「最終の帰り便」を求める（乗りかえなし）。帰りののりばは300m以内まで探す。
- 行けて、滞在時間を過ごしたあとに帰りの便があるバス停を「ひとりで行ける」と判定する。
- 施設: 八戸圏は `app/data/pois_hachinohe.json`（OpenStreetMap、2026-10-31取得）。他地域は Overpass API。
